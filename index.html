Questions fréquentes

Faut-il un ordinateur ?

Un ordinateur est conseillé, surtout pour la suite. Pour démarrer, un éditeur de code en ligne sur téléphone suffit pour les premières leçons.

Je n’ai jamais programmé, est-ce pour moi ?

Oui. Chaque leçon commence par une explication simple, avec une analogie, puis un exercice guidé.

Oui, les modules suivants sortent progressivement. Dis-moi sur WhatsApp que tu veux être prévenu.
